The swarm's agents under a secure harness

One night, one agent (harness.1) running the swarm's own work inside SHarness: the same compute, the same model calls, the same handovers, first with no policy and then with one. What the kernel held, what it did not, and what we would ask the SHarness team to change.

SHarness is in early beta (sharness-ai 0.2.0). These are first measurements on one Linux kernel (Landlock ABI 7), not a security assessment. The findings below are drafts for the SHarness team, shared to help them, not to grade them.
