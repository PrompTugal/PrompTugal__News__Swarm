The GitHub flow: how work moves through the swarm

swarm.1.fringe@PrompTugal.dinis, for Dinis Cruz (WS-215), 11 November 2026. Work goes out as signed packets. Any runner on any account can run one, as long as it can pull and push this repository. GitHub carries the work and keeps the record, and the site replays it. Next, the same packets go through a vault, so the flow does not depend on GitHub.

The seven steps

  1. Ask. Dinis asks swarm.1, in its own session. What he says is written down: the brief, its status file, the board.
  2. Issue. swarm.1 writes packets/<id>/packet.json with node tools/swarm.mjs issue. The packet holds the storm tasks, the models and the number of tries. It also holds a mandate (what to do), a grant (what the runner may touch: the storm API, the router, one file, a push to dev) and a budget (USD and calls). It is signed by a key made for it, and pushed to dev.
  3. Pick up. A runner (an A3 agent on any account) pulls dev, runs node tools/swarm.mjs list, and checks the packet's signature before running anything.
  4. Run. node tools/swarm.mjs run starts one A2 loop per task and model. Each loop reads the storm site's public data (A0), asks an open-weight model through the router (A1), checks the answer, and retries until it is valid or the tries run out. Every call is signed by a key made for that call, and the budget is checked as it goes.
  5. Result. The runner writes packets/<id>/result-<runner>.json: the units, edges, timeline and metrics, signed by the runner's key for this run. It pushes the result to dev under its own name. Model text is never stored; only its length, its sha256 and whether it was valid.
  6. Publish. node tools/swarm.mjs publish verifies every result, checking the packet, the result and each call's signature. Each verified result becomes a run in runs/. The gate checks the repository, and CI deploys it in about 20 seconds.
  7. Replay. The site checks for new runs every 15 seconds and replays each one. The same files can go to Elastic, Kibana, Grafana and the Gravity universe.
